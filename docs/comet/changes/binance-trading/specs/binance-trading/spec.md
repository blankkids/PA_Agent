# binance-trading 目标规格

Binance 真实交易执行（现货 + USDT-M 永续合约）：AI 决策经人工确认后在币安下单（Testnet 默认），合约支持做多/做空，止盈 TP1/TP2 分批各半，含自动保护与账户管理。

## 需求

### R1 AI 决策转订单计划（双市场）

系统将阶段二交易决策转换为可执行订单计划：市价决策生成市价单（现货按 USDT 金额 quoteOrderQty；合约按金额与杠杆折算数量）；限价/突破决策生成挂 entry_price 的限价单；数量与价格按交易对过滤器（stepSize/tickSize/minNotional）向下截断。合约市场接受做多（BUY）与做空（SELL 开空）；现货市场做空时拒绝生成订单并提示切换到合约市场。

### R2 强制人工确认下单

任何真实下单前展示订单确认对话框，完整列示市场（现货/合约）、方向、订单类型、金额或价格、数量、杠杆（合约）、止损价、TP1/TP2（含分批数量说明）、当前环境（Testnet/实盘徽标）；仅在用户显式确认后提交。交易总开关未启用或未配置 API Key 时，入口提示并引导打开交易设置对话框，不发起交易请求。

### R3 保护单策略

- **现货 · 未设 TP2**：市价成交后挂一组 OCO（止盈 TP1 全量 + 止损 SL 全量）
- **现货 · 设 TP2**：挂两组 OCO——TP1 半量+SL 半量、TP2 半量+SL 半量（同 SL 价）；任一 TP 成交其同组 SL 腿联动取消，价格触及 SL 时剩余持仓全部了结
- **合约**：TP1/TP2 各半量 reduceOnly 止盈单；SL 为 closePosition 型止损（剩余仓位全平）；做空时 SL/TP 方向自动反转
- TP2 未设置时不挂第二档；保护单提交失败向用户报告原因，不影响已成交入场

### R4 限价入场成交检测

限价入场提交后，后台线程以固定间隔轮询订单状态（失败退避重试），检测到成交按实际成交量自动提交保护单。程序下次启动交易功能时扫描「已成交但无保护单」的持仓并提示补挂保护。

### R5 账户管理

提供余额查询（资产/可用/冻结，非零过滤，后台线程，失败中文提示）、合约持仓查询（数量/方向/开仓价/未实现盈亏/杠杆）、当前交易对挂单列表（单笔撤单；一键撤全部需确认）、市价平仓（确认对话框展示平仓方向/数量/参考价/市场与环境；平仓同时撤销该交易对剩余保护挂单；无持仓时不可用）。

### R6 配置与安全

- `trade_enabled` 总开关默认关闭；关闭时所有下单入口不可用且不发起签名交易请求
- `market` 全局开关默认 spot（现货）/ futures（USDT-M 合约）；切换后行情、下单、保护单、账户面板整体路由到对应市场
- 合约 `leverage` 默认 5、范围 1-20，可配置；下单前按设置调整杠杆并在确认对话框回显；使用单向持仓模式
- 每笔金额 `stake_usdt` 可配置且受上限 `max_stake_usdt`（默认 10000）约束，超限拒绝并提示
- API Key 明文存储；API Secret 以 Windows DPAPI 加密存储，配置文件与执行留痕不含明文；解密失败（如换机）时提示重新录入，不静默失败
- Testnet 默认启用；切实盘前弹红色风险警告，仅明确确认后生效；环境标记在确认对话框、交易面板与状态提示一致可见
- 交易与行情请求复用 Binance 代理策略（显式配置优先、自动探测本地代理端口）；网络不可达给出含检查代理建议的中文提示

### R7 合约行情模式

market=futures 时，K 线数据切换为合约行情（合约 klines REST + 合约 WebSocket 流），数据源行为（周期、订阅、快照语义、断流兜底）与现货模式一致；切回现货恢复现货行情。

### R8 下单错误友好化

交易所拒绝原因转换为中文可操作提示：余额不足（含所需与可用金额）、保证金不足、数量/精度不符、最小名义价值不满足、时钟偏差超窗（初始化时校验本机与服务器时间偏差）、网络不可达；原始错误码保留在执行留痕。

### R9 执行留痕

下单、撤单、平仓追加写入 `trade_records/executions.jsonl`：时间、市场、环境、决策摘要（方向/类型/entry/SL/TP1/TP2）、订单号、数量、价格、状态、错误码；永不写入 API Secret。

## 验收示例

1. 现货市价闭环：配 Key（现货）→ 市价做多 → 确认 → 成交 → OCO → 面板 → 撤单/平仓 → 留痕
2. 现货 TP 分批：TP1+TP2 → 两组 OCO 各半量；TP1 成交后剩余半量仍受保护
3. 合约做多闭环：切合约（行情自动切）→ 市价做多 → TP1/TP2 各半 reduceOnly + closePosition SL → 持仓/杠杆可见
4. 合约做空：做空决策 → SELL 开空 → SL/TP 方向反转正确
5. 杠杆：默认 5x，调整后下单前生效并回显
6. 现货做空拦截：提示切合约市场，不下单
7. 限价成交检测：挂单成交 → 自动挂保护单 → 通知
8. 未启用/未配 Key：引导配置，无交易请求
9. 实盘切换：红色警告确认；取消保持 Testnet
10. 余额不足：中文提示所需与可用金额
11. 金额超限：拒绝并提示上限
12. Secret 安全：落盘仅密文；留痕无 Secret；重启解密可用
